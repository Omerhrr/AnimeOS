     1→# AI-Native Animation Production Platform
     2→
     3→> **An AI-native production system for creating, managing, and operating complete animated productions using DSH, Blender, and open-source infrastructure.**
     4→
     5→---
     6→
     7→# 1. Vision
     8→
     9→Build a production platform where a creator can describe an animated production in natural language and **DSH orchestrates the entire production pipeline**.
    10→
    11→The platform should support:
    12→
    13→* Donghua
    14→* Anime
    15→* Korean / manhwa-inspired animation
    16→* General animation
    17→* 3D animation
    18→* 2D animation
    19→* Hybrid 2D/3D animation
    20→* Feature films
    21→* Series
    22→* Short films
    23→* Episodic productions
    24→* Multilingual subtitles
    25→* Optional dubbing
    26→
    27→The system should not merely generate isolated images or clips.
    28→
    29→It should maintain a **persistent animated universe** containing:
    30→
    31→* Characters
    32→* Character development
    33→* Character variants
    34→* Clones
    35→* Avatars
    36→* Transformations
    37→* Reincarnations
    38→* Possession states
    39→* Environments
    40→* Props
    41→* Creatures
    42→* Abilities
    43→* Animation libraries
    44→* Scenes
    45→* Shots
    46→* Story state
    47→* Continuity
    48→* Audio
    49→* Localization
    50→* Rendering
    51→* Production history
    52→
    53→The central idea:
    54→
    55→> **DSH is the brain. Blender is the production engine. The platform is the production environment.**
    56→

   180→# 5. DSH: The Brain
   181→
   182→DSH is responsible for:
   183→
   184→* Understanding user intent
   185→* Planning production tasks
   186→* Calling tools
   187→* Maintaining context
   188→* Maintaining production state
   189→* Maintaining character state
   190→* Maintaining story state
   191→* Detecting missing assets
   192→* Detecting continuity conflicts
   193→* Coordinating Blender
   194→* Coordinating media tools
   195→* Evaluating previews
   196→* Deciding when to retry
   197→* Deciding when to modify
   198→* Deciding when a shot is complete
   199→* Managing long-running production workflows
   200→
   201→The core loop is:
   202→
   203→```text
   204→INTENT
   205→  ↓
   206→PLAN
   207→  ↓
   208→EXECUTE
   209→  ↓
   210→OBSERVE
   211→  ↓
   212→EVALUATE
   213→  ↓
   214→MODIFY
   215→  ↓
   216→EXECUTE
   217→  ↓
   218→APPROVE
   219→```
   220→

   222→
   223→# 6. DSH Should Not Directly Write Random Blender Scripts
   224→
   225→Avoid making the architecture:
   226→
   227→```text
   228→User
   229→ ↓
   230→LLM
   231→ ↓
   232→Huge Blender Python script
   233→ ↓
   234→Blender
   235→```
   236→
   237→Instead:
   238→
   239→```text
   240→User
   241→ ↓
   242→DSH
   243→ ↓
   244→Domain Tool
   245→ ↓
   246→Production API
   247→ ↓
   248→Blender Bridge
   249→ ↓
   250→Blender Python API
   251→```
   252→
   253→DSH operates at a high production level.
   254→
   255→For example:
   256→
   257→```text
   258→character.create()
   259→scene.create()
   260→character.add_to_scene()
   261→camera.create()
   262→lighting.create()
   263→animation.apply()
   264→vfx.create()
   265→render.preview()
   266→render.final()
   267→```
   268→
   269→The Blender bridge handles the actual `bpy` operations.
   270→
   271→This creates a stable abstraction layer between DSH and Blender.

   826→# 19. Character State Types
   827→
   828→DSH must distinguish:
   829→
   830→## Permanent Development
   831→
   832→Example:
   833→
   834→```text
   835→Lin Yue loses his left arm.
   836→```
   837→
   838→This changes his canonical state from that point onward.
   839→
   840→## Temporary Scene State
   841→
   842→Example:
   843→
   844→```text
   845→Lin Yue is covered in blood.
   846→```
   847→
   848→This applies to the scene but does not permanently alter the character.
   849→
   850→## Variant
   851→
   852→Example:
   853→
   854→```text
   855→Lin Yue wears formal robes.
   856→```
   857→
   858→This is an appearance variant.

   908→         ├── Clone 002

   912→
   913→They can share:
   914→
   915→* Model
   916→* Rig
   917→* Materials
   918→* Animation library
   919→* Base clothing
   920→
   921→while having unique:
   922→
   923→* Position
   924→* State
   925→* Equipment
   926→* Damage
   927→* Abilities
   928→* Temporary effects
